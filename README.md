# Hussein Badr English — Complete Website

منصة تعليمية عربية متكاملة لتعلم اللغة الإنجليزية من الصفر إلى الاستخدام العملي.

## النشر السريع
- اسم المستودع المقترح: `hussein-badr-english`
- النشر: GitHub Pages → Deploy from a branch → `main` → `/(root)`
- يجب أن يكون `index.html` في الجذر مباشرة.
- ارفع محتويات ZIP بعد فك الضغط، ولا ترفع ZIP نفسه.

## مكونات الموقع
- الصفحات الرئيسية والدروس والقواعد والمفردات والاختبارات والبطاقات.
- صفحات الاستماع والتحدث والقراءة والكتابة والنطق والتدريب اليومي.
- لوحة تقدم محلية وميزة تصدير/استعادة النسخة الاحتياطية.
- تصميم RTL متجاوب مع الهاتف والتابلت، ولوحة ألوان حسين بدر الرسمية.
- PWA وService Worker للعمل الجزئي دون اتصال بعد زيارة الموقع.

## الهوية الرسمية
Navy `#102B4C` · Yellow `#FFD447` · White `#FFFFFF` · Support blue `#7598BD` · Pale gray `#F5F7FA`.

## الخصوصية والقيود
هذا موقع ثابت؛ لا توجد قاعدة بيانات أو حسابات مستخدمين أو مزامنة سحابية. بيانات التقدم تحفظ في المتصفح المحلي فقط. بعض ميزات النطق تعتمد على دعم المتصفح.

اقرأ `START-HERE-AR.txt` و`docs/PUBLISH-NEW-REPOSITORY-AR.md` قبل النشر.
